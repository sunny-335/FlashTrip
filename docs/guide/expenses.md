# 费用预算

## 记账

- 每笔费用包含分类（餐饮 / 住宿 / 交通 / 门票 / 购物 / 其他）、金额、币种、发生时间与备注。
- 支持多币种：每笔可记录币种与汇率，汇总页按分类聚合。
- 费用可关联到某个行程日或某个计划项，分日小计自动汇入行程手册。

## 智能分账

多人出行时支持五种分账模式：

| 模式 | 说明 |
| --- | --- |
| 均摊 | 所有成员平均分摊 |
| 儿童免账 | 儿童不参与分摊 |
| 按家庭 | 以家庭为单位分摊 |
| 自定义 | 手工指定每人份额 |
| 仅记垫付 | 只记录垫付人，不做分摊 |

每笔费用可指定垫付人，行程结束时可按成员结算「应收 / 应付」。

## 行程级预算

行程可设置预算总额（币种随行程）。仪表盘与费用页展示预算使用进度、已花费与剩余；导出的 PDF 行程手册会在「行程总览」中包含预算概览与进度条。

## 导出

费用随行程一起导出到 PDF 行程手册（分类汇总表 + 占比 + 总计）；多币种记录时手册会注明合计未做汇率换算。
