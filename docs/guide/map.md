# 地图

地图基于 MapLibre GL JS 渲染，底图供应商可在安装向导或设置页选择与切换。

## 支持的底图

| 供应商 | 类型 | 密钥 |
| --- | --- | --- |
| OpenFreeMap（多种样式） | 矢量 | 无需密钥 |
| Mapbox | 矢量 | 需要 token |
| 高德地图 | 栅格 | 瓦片可免密使用；POI / 路径规划需 Web 服务 key |
| 天地图 | 栅格 | 需要 tk（含注记图层） |

各供应商的详细密钥说明见[地图 Provider 配置](/settings/map)。

## 功能

- **足迹地图**：汇总全部行程到访过的地点，形成足迹视图。
- **选点与检索**：通过地图供应商的 POI / 地理编码服务搜索地点，落点直接进入待规划池。
- **底图署名**：预设元数据自动带出供应商署名与审图号，切换供应商时一并更新。
- **坐标系**：所有坐标以 WGS84 入库并带 `coord_system` 标记，展示层按供应商自动纠偏。

::: warning 底图切换
切换底图样式属于破坏性操作，标记与覆盖层需要相机快照与重放；切换后若标记消失，刷新页面即可恢复。
:::

## 瓦片代理与密钥安全

瓦片 URL 中的密钥占位符由后端代理注入，密钥绝不拼进返回给前端的样式对象；高德 / 天地图等多凭据场景下，浏览器端凭据（如高德 `security_js_code`、天地图 `browser_tk`）与服务端凭据分开存储、分开加密。
