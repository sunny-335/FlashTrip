# 协作与分享

## 协作成员与权限

- 行程可邀请多个成员协作，权限为**细粒度**控制（行程读 / 写、计划、预订、交通、费用、瞬间等独立授权）。
- 邀请通过链接完成：被邀请者首次登录时设置密码，管理员可开启「首次设密 / 强制改密」策略。
- 密码策略可配置（长度、复杂度），全程实时强度评估。

## 公开分享

行程可生成**公开只读**链接，无需登录即可查看：

- 分享内容可勾选：行程概要、每日安排、交通、酒店 / 预订、物品清单、公开瞬间照片。
- 费用信息**默认不分享**，可选开启。
- 瞬间照片逐条控制可见性：只有标记为公开的照片才会出现在分享页。
- 分享页图片通过公开上传端点提供，端点内部按「公开瞬间引用」二次校验。

## 权限模型要点

- 权限校验在服务端逐请求执行（`trip:read` / 写权限等），前端隐藏仅为交互层。
- 邀请链接、分享链接均使用不可猜测的随机标识。
- 撤销分享 / 移除成员即时生效。
