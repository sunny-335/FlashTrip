# 天气与邮件

## 出行前天气建议

- 系统在出行前通过守护线程自动查询目的地天气，并通过邮件发送**出行建议**（穿衣、雨具等提示）。
- 天气查询按「供应商 + 城市 + 天数」缓存，命中缓存直接返回，避免频繁请求。
- 天气供应商与密钥配置见[天气服务](/settings/weather)。

## 邮件通知

- 邮件由标准库 `smtplib` 发送，零额外依赖；SMTP 配置见[邮件（SMTP）](/settings/mail)。
- 发送失败只记录异常类型名（SMTP 异常消息可能回显账号口令），不会把敏感信息写进日志。
- 支持发送测试邮件验证连通性。

## 提醒守护线程

- 天气提醒调度随应用启动自动开启，异常不阻断主服务。
- 可在设置中整体关闭天气提醒。
