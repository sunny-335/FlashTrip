# 行程规划

行程规划是瞬旅的核心模块：以「天」为骨架、以卡片为血肉，支持自由拖拽与 AI 辅助。

## 每日时间线

- **三栏拖拽**：地点、交通、备注卡片可在「待规划池」与任意一天之间拖拽，位置由分数索引（fractional indexing）排序，多端并发不冲突。
- **卡片信息**：地点卡片包含开始时间、时长、结束时间，三者自动联动；地址、备注、坐标一并保存。
- **冲突标红**：同一时间段内重叠的安排会标红提示，可一键调用 AI 重排。
- **自动保存**：所有修改自动保存，无需手动点保存；支持撤销批量拖拽。

## 地点与交通卡片

- 地点卡片可记录名称、地址、坐标（WGS84 入库并带坐标系标记）、参观时长与备注。
- 交通卡片记录方式（飞机 / 火车 / 自驾 / 大巴 / 轮渡 / 步行）、起终点、出发到达时间、承运方与座位，可与某个地点或某一天关联。
- 地图上选点可直接落入待规划池，再拖入日程。

## 预订与瞬间

- **预订**：机票 / 酒店 / 火车 / 门票等，记录供应商、确认号、时间与金额，可关联行程日。
- **瞬间**：旅途中拍摄的照片可上传（支持对象存储直链，见[对象存储](/settings/storage)），逐条控制对外可见性，用于分享页展示。

## PDF 与日历导出

行程支持两种导出：

- **PDF 行程手册**：封面（行程名 / 目的地 / 日期 / 人数 / 统计）、行程总览（每日摘要、预算概览）、分日行程（地点卡片与当日交通、当日小计）、预订与交通表格、费用分类汇总，配色与站点主色一致，适合打印或分享。
- **ICS 日历**：把行程、地点、预订、交通写入标准日历（时间统一转为 UTC），可订阅到手机或日历软件。

## 物品清单

按行程维护打包清单，勾选状态实时保存，支持协作成员共同编辑。
