# 天气服务

天气供应商配置位于「设置 → 天气」（config.json 的 `weather` 段），密钥经 Fernet 加密存储（`*_enc`），仅在请求瞬间解密。

## 支持的供应商

| 供应商 | 密钥字段 | 说明 |
| --- | --- | --- |
| uapis | `uapi_key` | 默认供应商，通用天气 API 聚合 |
| amap | `amap_key` | 高德天气（Web 服务 key，与地图服务 key 同源） |
| qweather | `qweather_key`（另可配 `qweather_host`） | 和风天气，支持自定义 API Host |

## 配置要点

- 供应商切换即刻生效；选择 `qweather` 时必须同时配置 API Host。
- 明文密钥保存后自动加密为 `*_enc`；表单留空表示保留旧密钥。
- 统一 8 秒超时，任一供应商失败会返回明确的错误提示（天气服务暂不可用）。
- 查询结果按「供应商 + 城市 + 天数」缓存，命中且未过期直接返回，避免频繁外呼。

## 出行提醒

- 开启后，系统在行程出行前自动查询目的地天气并发送建议邮件（需要先配置 SMTP，见[邮件设置](/settings/mail)）。
- 提醒调度为后台守护线程，随应用启动自动运行，可整体关闭。
